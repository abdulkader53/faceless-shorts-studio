## ⏰ The Global Posting Algorithm Windows (High Tier-1 Traffic)

YouTube Shorts distribution spikes when Tier-1 audiences (US, UK, Canada, Australia) are active:
* **Weekday Sweet Spot**: **12:00 PM – 2:30 PM EST** (9:00 AM – 11:30 AM PST | 5:00 PM – 7:30 PM GMT | 9:30 PM – 12:00 AM IST).
  * *Why*: Catches US lunch breaks and UK/Europe evening commutes.
* **Weekend Sweet Spot**: **9:30 AM – 11:30 AM EST** (Saturday & Sunday mornings).
  * *Why*: Highest weekend browsing volume before afternoon activities.
* **Cadence**: 1 Short per day, alternating daily between **History** and **Wildlife** (or simultaneous uploads on both dedicated channels).

## ⚡ Daily 25-Minute Execution Workflow

Follow this repeatable daily checklist:
1. **00:00 – 05:00**: Run `studio.cmd create <key>` or edit `script.json` for the day's scheduled topic.
2. **05:00 – 08:00**: Run voice generation and Whisper word alignment:
   ```bash
   python faceless-shorts/scripts/voice.py channel-<niche>/shorts/<name>
   python faceless-shorts/scripts/words.py channel-<niche>/shorts/<name>
   ```
3. **08:00 – 15:00**: Verify `capture.mjs check` and render the final MP4:
   ```bash
   node tools/capture.mjs video renders/short.mp4
   ```
4. **15:00 – 20:00**: Run `studio.cmd ctr channel-<niche>/shorts/<name>` to generate the 3 candidate cover frames and copy the title & tags.
5. **20:00 – 25:00**: Upload to YouTube Studio via desktop or mobile app:
   - Select the extracted candidate cover frame as thumbnail.
   - Paste the optimized Title & Description with `#shorts`.
   - Schedule for the exact target posting window!
